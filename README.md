# CriacaoSite — divulgação

🔗 **Página:** https://adrianoms2004.github.io/CriacaoSite_pub/

Gerador de sites estáticos com wizard guiado, 12 paletas + custom, IA opcional e admin por site.

Este repositório contém apenas a página de divulgação (como em `GmSafeCare-HomeCare_pub`). O código principal está em https://github.com/adrianoms2004/CriacaoSite (privado).

## Acesso
- Criador: http://localhost:3000/criar (ou https://criacaosite.gmsafecare.com/criar)
- Admin central: `/admin` (senha `admin+DDMM`)
- Admin por site: `/sites/[slug]/admin/`

## Tecnologias
Next.js 16, TypeScript, Turbopack, Tailwind, Docker, Caddy
